# POSH360 Deck - Canva Build Instructions (Step-by-Step)

## Quick Setup
1. Go to **canva.com**
2. Create new design → Select **"A4"** format
3. Set up your brand colors (see below)

---

## BRAND COLORS (Add to Canva)
Copy these hex codes into Canva's color palette:
- **Primary Blue:** #1B3A6B (Headlines, authority)
- **Accent Red:** #E63946 (Warnings, urgency)
- **Text Gray:** #2C3E50 (Body copy)
- **White:** #FFFFFF (Backgrounds)
- **Light Gray:** #F5F5F5 (Card backgrounds)
- **Gold:** #D4AF37 (Stats, achievements)

## TROUBLESHOOTING

**Slide looks cluttered?**
- Increase spacing between elements
- Use more white space
- Reduce font sizes slightly

**Colors don't match?**
- Use the hex codes above exactly
- Check Canva's color picker

**Text overlaps?**
- Adjust text box sizes
- Use smaller fonts for secondary text
- Reorganize layout

**Need to customize?**
- Replace company details, phone, email, testimonials with YOUR information
- Adjust founder bio with actual details
- Use your real POSH360 logo
