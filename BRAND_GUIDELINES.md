## Typography

### Font Stack

| Element | Font Family | Weight | Size | Line Height | Letter Spacing |
|---------|-------------|--------|------|-------------|-----------------|
| **Headings (H1)** | `'Inter', 'Poppins', -apple-system, sans-serif` | Bold (700) | 48px / 2.5rem | 1.2 | -0.02em |
| **Headings (H2)** | `'Inter', 'Poppins', -apple-system, sans-serif` | Bold (700) | 36px / 2.25rem | 1.3 | -0.01em |
| **Headings (H3)** | `'Inter', 'Poppins', -apple-system, sans-serif` | SemiBold (600) | 24px / 1.5rem | 1.4 | 0 |
| **Subheadings** | `'Inter', 'Poppins', -apple-system, sans-serif` | Medium (500) | 16px / 1rem | 1.5 | 0 |
| **Body Text** | `'Inter', 'Poppins', -apple-system, sans-serif` | Regular (400) | 16px / 1rem | 1.6 | 0 |
| **Small Text** | `'Inter', 'Poppins', -apple-system, sans-serif` | Regular (400) | 14px / 0.875rem | 1.5 | 0 |
| **Button Text** | `'Inter', 'Poppins', -apple-system, sans-serif` | Medium (500) | 16px / 1rem | 1.5 | 0.5px |

### Font Weights Used
- **400** - Regular (body text, default)
- **500** - Medium (buttons, subheadings)
- **600** - SemiBold (H3, emphasis)
- **700** - Bold (H1, H2, strong emphasis)

### Typography Rules
- ✅ Use Inter or Poppins as primary fonts
- ✅ Maintain consistent line heights for readability
- ✅ Use letter-spacing for headings to improve visual hierarchy
- ✅ Never use font sizes below 14px for body text
- ❌ Do NOT mix serif and sans-serif fonts in the same design
- ❌ Do NOT use script or decorative fonts for body content

## Logo Guidelines

### Logo Files
- **Full Logo:** `tranzact-logo.png` - Use for primary branding
- **Icon Variant:** `Logo-icon.jpg` - Use for favicons, small spaces
- **Square Variant:** `Logo-square.jpg` - Use for avatars, profile images

### Logo Usage Rules

#### ✅ **DO:**
- Use the full logo on white or light backgrounds
- Maintain minimum clear space (at least 20px padding around logo)
- Scale proportionally without distortion
- Use high-resolution versions for print materials
- Place logo in top-left corner of web pages/documents

#### ❌ **DON'T:**
- Stretch, skew, or rotate the logo
- Change logo colors or apply filters
- Use logo at sizes smaller than 100px wide
- Place logo on complex/busy backgrounds without white space
- Add drop shadows, glows, or effects to the logo

## Button & UI Elements

### Primary Button
```
Background Color: Primary Blue (#0066CC)
Text Color: White (#FFFFFF)
Font Weight: Medium (500)
Font Size: 16px
Padding: 12px 24px
Border Radius: 6px
Border: None
Cursor: pointer

States:
- Hover: Darken blue by 15%
- Active/Pressed: Darken blue by 25%
- Disabled: Gray background (#9CA3AF), reduced opacity (0.5)
```

**Examples:** "Book A Demo", "Start for Free"

### Secondary Button
```
Background Color: Light Gray (#F3F4F6)
Text Color: Dark Slate (#1F2937)
Font Weight: Medium (500)
Font Size: 16px
Padding: 12px 24px
Border Radius: 6px
Border: 1px solid Medium Gray (#9CA3AF)

States:
- Hover: Light Gray background darkens slightly
- Active/Pressed: Dark slate text
- Disabled: Opacity reduced (0.5)
```

### Button Sizing
- **Large:** Padding 16px 32px (for primary CTAs)
- **Regular:** Padding 12px 24px (default)
- **Small:** Padding 8px 16px (for secondary actions)

### Icon Styling
- Size: 20x20px for standard buttons
- Color: Inherit text color
- Spacing: 8px gap between icon and text
- Alignment: Center-aligned with text

## Imagery & Visual Style

### Photography & Visual Guidelines
- **Style:** Modern, professional, relatable
- **Color Tone:** Bright, well-lit, minimal shadows
- **People:** Diverse representations of Indian manufacturers, diverse team
- **Manufacturing:** Show real factory/production environments
- **Avoid:** Stock photography that looks overly staged or generic

### Icon Style
- Use consistent stroke weight (2px)
- Rounded corners (4-6px radius)
- Minimize detail for scalability
- Maintain 20x20px or 24x24px standard size
- Color: Match text color or use primary blue

### Charts & Data Visualization
- Use primary blue as main color
- Secondary colors for comparison/contrast
- Clear labels and legends
- Sufficient contrast for accessibility

## Spacing & Layout

### Margin & Padding System (8px Grid)

| Unit | Size | Usage |
|------|------|-------|
| **xs** | 4px | Small spacing within components |
| **sm** | 8px | Component padding, small gaps |
| **md** | 16px | Standard spacing between elements |
| **lg** | 24px | Section spacing, larger gaps |
| **xl** | 32px | Major section breaks |
| **2xl** | 48px | Page margin, large layout gaps |

### Layout Rules
- ✅ Use multiples of 8px for all spacing
- ✅ Maintain consistent spacing between sections (24-32px)
- ✅ Use white space to guide focus
- ❌ Do NOT use arbitrary pixel values (5px, 7px, 13px, etc.)
- ❌ Do NOT crowd multiple elements without sufficient spacing

### Container Width
- **Max-width:** 1200px for desktop layouts
- **Mobile:** Full width with 16px side margin
- **Tablet:** Full width with 24px side margin

## Brand Tone & Voice

### Brand Personality
- **Confident:** Speak with authority about manufacturing solutions
- **Approachable:** Use clear, jargon-free language
- **Action-Oriented:** Emphasize outcomes and results
- **Trustworthy:** Highlight security, certifications, and track record

### Messaging Pillars
1. **Simplicity:** "WhatsApp-style ease" - easy to use, no learning curve
2. **Trust:** Bank-grade security, ISO certified, proven reliability
3. **Indian-First:** Built for Indian manufacturers, understands local context
4. **Results:** Real-time insights, measurable impact, tangible ROI
5. **Credibility:** Founded by IIT/IIM grads, trusted by 10,000+ users

### Copy Tone
- **Headings:** Bold, benefit-driven ("Can you afford to wait?")
- **Body Copy:** Clear, conversational, actionable
- **CTAs:** Urgent but friendly ("Book A Demo", "Start for Free")
- **Error Messages:** Helpful, not blaming
- **Success Messages:** Celebratory, encouraging

### Examples

#### ✅ **DO Say:**
- "Real-time visibility across your factory floor"
- "Trusted by 10,000+ Indian manufacturers"
- "Bank-grade security, built for Indian businesses"
- "Start for free, scale as you grow"

#### ❌ **DON'T Say:**
- "Our enterprise ERP solution..."
- "Advanced machine learning algorithms..."
- "Cutting-edge digital transformation platform..."
- "Leverage synergies across your supply chain..."
