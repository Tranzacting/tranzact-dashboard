## Full-funnel layer check

Uniformity across campaigns is the main finding:
- **Call connect rate:** 30-33% system-wide (W-0 32.6 / W-1 32.7 / W-2 30.9 / W-3 25.7 / W-4 27.0). Roughly 2 of 3 MQLs never reach a human.
- **Avg call attempts:** ~5 per lead. Not obviously under-worked.
- **SD+ sentiment rate:** 18-24% across campaigns. If this is a true qualification signal, SQL% should track closer to it — actual SD+ → SQL conversion sits at ~16%.
- **ICP verified:** 0 across the board — either `is_icp_industry` not being populated or filter semantics differ; worth a separate audit.

Since layers are uniform, campaign-level pause/scale moves small amounts of the total SQL number. The biggest lever is **raising connect rate**.
